Event Management System

📌 About

A Java Swing desktop application with MySQL database that allows admins to manage events and participants to view and register for events.

⚙️ Features
* Role-based login (Admin / Participant)
* Event management (Add, Edit, Delete)
* Event registration system
* Participant viewing

🛠️Tech Stack
* Java (Swing)
* MySQL
* JDBC
* VS Code

▶️How to Run
1. Open project in Java IDE
2. Configure MySQL database
3. Add libraries from `libs/`
4. Run `Login.java`
